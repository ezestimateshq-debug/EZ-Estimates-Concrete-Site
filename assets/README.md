# Public Launch Site Assets

This folder is for public website assets only.

Expected public files:

- `sample-proposal.pdf`
- `sales-one-pager.pdf`

Add only approved public PDF files to this folder.

`sample-proposal.pdf` should be added only after a public-safe sample proposal is generated and approved.

Do not place app downloads, local databases, source workbooks, pricing notes, customer records, or support-only files in this public assets folder.

Do not publish installer files, activation credentials, customer data, lead trackers, or pricing notes here.

Demo and Founder Plan request buttons are configured in `../site-config.js`.
